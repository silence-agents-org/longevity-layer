# Free downloads

Free, printable materials for keeping **multi-year personal records** honest. Use them with the [ledger](../README.md) or with paper. Apache-2.0, like the repo.

**Not medical advice.** These are record-keeping and statistics tools. They don't diagnose, predict, or promise any health or lifespan outcome. Nothing here uses AI. Every method reference is listed with its URL in [SOURCES.md](SOURCES.md) (checked 2026-10-26).

| 02 | Device-switch checklist (keep trends comparable) | [checklist](02-device-switch-checklist.md) |

| 05 | Annual review worksheet | [worksheet](05-annual-review-worksheet.md) · [printable](05-annual-review-worksheet.html) |

**Download everything:** clone the repo, or GitHub → Code → Download ZIP. To get a PDF, open a printable `.html` file and use File → Print → Save as PDF.
